# 0001. WebAuthn RP ID and origins

- Status: Accepted
- Date: 2026-11-16

## Context

Passkeys (WebAuthn credentials) are bound to the Relying Party ID (RP ID). If the RP ID changes after users have registered, every registered passkey becomes unusable, and there is no migration path for WebAuthn credentials.

AegisID runs as one Cloudflare Worker serving one origin. Tenancy is by path (`/t/{slug}`), so all tenants share a single RP ID. Preview deployments run on per-branch hostnames of the form `<branch>.aegis.lmnfrs.org`, so the expected origin differs per preview while the RP ID stays the same.

## Decision

- `RP_ID = "aegis.lmnfrs.org"` in production (`vars`) and in previews (`previews.vars`).
- `RP_ORIGIN = "https://aegis.lmnfrs.org"` in production.
- Previews set `RP_ORIGIN = "https://*.aegis.lmnfrs.org"`. `expectedOrigin()` in `src/worker/dev/webauthn.ts` resolves this per request to the request's own origin, but only when the request is `https` and the host is exactly one DNS label in front of `aegis.lmnfrs.org`. Any other host returns the unmatched pattern, so verification fails closed.
- Local development uses `RP_ID=localhost` and `RP_ORIGIN=http://localhost:5173`, set in the gitignored `.dev.vars`.

## Consequences

- `RP_ID` is effectively permanent. Changing it invalidates all registered passkeys.
- A passkey registered on a preview is also offered by browsers on production, because the RP ID is shared. Previews use a separate D1 database, so the server will not recognise such a passkey on production. The reverse is also true.
- Local WebAuthn testing works only on `http://localhost:5173`. `127.0.0.1` and LAN IP addresses are different origins and will fail verification.
- Previews do not inherit `vars`, so every variable must be repeated under `previews.vars`. Today that is `RP_ID`, `RP_NAME` and `RP_ORIGIN`.
- The wildcard origin relies on the Worker being the only thing answering the preview hostnames. A new hostname under `aegis.lmnfrs.org` that is not a branch preview would also be accepted if it is one label deep and served by this Worker.
